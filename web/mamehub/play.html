      How to play

      Host a game

      • Click Host lobby, pick the game, then Play.
      • Use Copy join link and send that URL to players (up to 5 joiners / 6 total).
      • Seats are join order: host is P1, first joiner P2, then P3…
      • Everyone uses the same P1 keyboard / on-screen pad; MAMEHub maps that to your seat (P2, P3, …).
      • Wait for the mesh graph to show all green links, then Start game.
      • Kick anyone with red links; later players shift down a seat.

      Join a game

      • Open the host’s join link — the cart is already chosen.
      • Your browser meshes with the host and every earlier joiner.
      • Wait until the host starts the game.

      Change inputs

      • After the emulator is running, click Controls (or press Tab) to open MAME Input Settings.
      • Before play, Controls opens a shell remap panel for sticky keyboard → pad bindings.

      Save / load state

      • Save state writes a single snapshot for the current game into this browser’s storage.
      • Load state restores that snapshot. It replaces the current session.

      Gamepad button

      • Gamepad shows or hides the on-screen pad (touch / mouse).
      • On phones and tablets it starts visible by default; on desktop it starts hidden.

      Fullscreen

      • Fullscreen puts the game on the entire screen and hides the rest of the site.
      • Press Escape or Exit fullscreen to return to the page.

      Keyboard controls (shell)

      Emulator not running yet — remaps here drive sticky force_input after play starts. Once the game is up, Controls opens MAME Input Settings instead.
